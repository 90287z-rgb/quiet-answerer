# Quiet Answerer — «Тихий автоответчик»

Бесплатный Android-«автоответчик»: одним касанием (виджет или кнопка) телефон
переходит в бесшумный режим на выбранное время, а входящие звонки в этот
период сбрасываются и/или получателю автоматически отправляется SMS с вашим
текстом. Без рекламы, без аналитики, без премиум-замков — все функции открыты.

## Возможности

- Индивидуальные каналы глушения: рингтон, музыка, системные звуки, уведомления, будильник (по умолчанию будильник не глушится).
- Запоминание и точное восстановление состояния звука при выключении; страховка от «зависшей тишины» после перезагрузки.
- Сессии с таймером автоотключения: пресеты 5/15/30/45/60 минут или произвольное время (AlarmManager).
- Автоответы SMS: библиотека статусов, валидация длины одного SMS, ограничение частоты (15/30/60/360/720 мин), режим «только контакты из телефонной книги», не более одного ответа на номер за сессию.
- VIP-список: избранные контакты доходят как обычно, остальные — по политике.
- Журнал звонков и ответов со статусами доставки (pending/sent/fail).
- Виджет главного экрана: тумблер, текст текущего автоответа, счётчики звонков/ответов, индикатор таймера и предупреждение о отсутствии DND-доступа.
- Локализации RU/EN, тёмная тема.

## Требования для сборки

- JDK 17
- Android SDK (compileSdk 35, minSdk 24) — путь указывается в `local.properties` (`sdk.dir=...`)

## Сборка

```bash
git clone <этот репозиторий>
cd quiet-answerer
./gradlew :app:assembleDebug        # debug-APK для тестов
./gradlew :app:bundleRelease        # AAB для маркета (нужен signingConfig, см. app/build.gradle.kts)
```

Артефакты:

- `app/build/outputs/apk/debug/app-debug.apk`
- `app/build/outputs/bundle/release/app-release.aab`

Установка на телефон:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Или вручную: скачать APK, разрешить установку из «неизвестных источников»,
пропустить предупреждение Play Protect (приложение не содержит вредоносного кода).

## Разрешения и приватность

| Разрешение | Зачем |
|---|---|
| `READ_PHONE_STATE` | Определить момент входящего звонка |
| `READ_CALL_LOG` | Узнать номер последнего входящего/пропущенного (на Android 10+ номер не отдаётся слушателю) |
| `READ_CONTACTS` | VIP-список и режим «только свои контакты» |
| `SEND_SMS` | Отправка автоответа только вашим активным текстом, по одному на номер за сессию |
| `ACCESS_NOTIFICATION_POLICY` (DND) | Настоящее глушение звонка/каналов звука |
| `ANSWER_PHONE_CALLS` | Сброс входящего вызова |
| `POST_NOTIFICATIONS`, `FOREGROUND_SERVICE(_SPECIAL_USE)` | Постоянное уведомление-индикатор активной сессии |
| `RECEIVE_BOOT_COMPLETED`, `WAKE_LOCK`, `SCHEDULE_EXACT_ALARM` | Восстановление/таймер после перезагрузки |

Все данные (журнал, статусы, VIP, настройки) хранятся только в локальной базе
и файлах SharedPreferences на устройстве. Никуда не отправляются и не
публикуются; интернет-разрешения у приложения отсутствуют.

## Известные ограничения

- Принудительный сброс входящего вызова (`End calls`) может не работать на
  некоторых ROM — это поведение системной телефонии, а не бага приложения.
- Настоящая тишина требует системного «Доступа Do Not Disturb»: приложение
  откроет нужный экран при первом включении; без доступа оно показывает
  предупреждение на виджете и продолжает автоответы.
